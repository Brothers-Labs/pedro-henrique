Como se joga
  1. Cada um coloca os seus nove feijões, um de cada vez.
  2. Depois é só andar para uma casa vizinha, seguindo as linhas.
  3. Três feijões seus em linha é uma trilha: você come um feijão do outro.
  4. Feijão que está dentro de uma trilha só pode ser comido se não sobrar outro.
  5. Quando restam três feijões, eles voam para qualquer casa vazia.
  6. Perde quem ficar com menos de três feijões ou sem ter para onde andar.
